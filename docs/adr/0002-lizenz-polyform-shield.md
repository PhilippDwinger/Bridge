# ADR 0002 – Lizenz PolyForm Shield 1.0.0

- **Status**: angenommen (09.11.2026, Paddy)
- **Kontext**: Bridge gehört Paddy; alle sollen es für eigene Projekte nutzen dürfen, aber niemand soll Bridge (auch
  verändert) als eigenes Produkt anbieten.
- **Entscheidung**: PolyForm Shield 1.0.0 ab Branch `bridge-4`. Erlaubt jede Nutzung außer Produkten, die mit Bridge
  oder Paddys Produkten auf Basis von Bridge konkurrieren.
- **Folgen**: Kein OSI-„Open Source“. Ältere Stände unter MIT bleiben MIT. Beiträge Dritter brauchen später eine
  Zustimmung (CLA), damit die Rechte bei Paddy bleiben.
